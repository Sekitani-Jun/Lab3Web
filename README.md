Belajar CSS Dasar

Repositori ini berisi kode dasar pembelajaran HTML dan CSS yang dibuat sebagai bagian dari mata kuliah Pemrograman Web di Universitas Pelita Bangsa. Proyek ini bertujuan untuk mengenalkan tag-tag dasar HTML serta cara mengimplementasikan CSS untuk mengatur tampilan halaman web.

📝 Deskripsi Proyek

Proyek ini adalah halaman web sederhana yang mendemonstrasikan berbagai cara penulisan CSS (Inline, Internal, dan Eksternal) serta penggunaan berbagai jenis CSS Selector (ID, Class, dan Tag/Element).

🚀 Konsep yang Dipelajari

Kode dalam proyek ini mencakup beberapa materi dasar Web Development:

Struktur Dasar HTML5: Penggunaan tag semantik seperti <header>, <nav>, dan <div>.

Cara Penulisan CSS (CSS Inclusion):

Inline CSS: Menambahkan style langsung pada atribut elemen (contoh: pada tag <p>).

Internal CSS: Menuliskan aturan CSS di dalam tag <style> pada bagian <head> HTML.

External CSS: Memanggil file CSS terpisah (style-eksternal.css) menggunakan tag <link>.

CSS Selectors:

Element Selector: Mengatur gaya berdasarkan nama tag (contoh: nav, h1, body).

ID Selector: Mengatur gaya elemen spesifik menggunakan atribut id (contoh: #intro).

Class Selector: Mengatur gaya elemen menggunakan atribut class (contoh: .button, .btn-primary).

Pseudo-class: Efek interaktif sederhana seperti nav a:hover.

CSS Specificity (Spesifisitas CSS):

Memahami prioritas deklarasi CSS ketika terjadi bentrokan aturan (contoh: ID Selector lebih kuat dibanding Class Selector).

Sistem Warna CSS:

Penggunaan format warna HEX (#20a759), RGBA (rgba(97, 179, 227, 0.24)), dan fungsi LAB (lab(35.16% 44.53 24.65)).

📂 Struktur File

index.html (atau nama file HTML utama Anda): Berisi struktur kerangka halaman web.

style-eksternal.css: File CSS terpisah yang mengatur tata letak, warna, dan dekorasi elemen seperti navigasi, area #intro, dan tombol.

💻 Cara Menjalankan

Pastikan file HTML dan style-eksternal.css berada di dalam folder yang sama.

Klik ganda pada file HTML tersebut.

Halaman web akan terbuka dan ditampilkan melalui aplikasi Web Browser (seperti Google Chrome, Mozilla Firefox, atau Microsoft Edge).
